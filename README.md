## 🌟 Возможности

* **Свободная камера (Free Camera):** Полный контроль над камерой для точного и удобного строительства в пространстве.
* **Интерактивное GUI-меню:** Удобный интерфейс для выбора объектов, цвета, параметров трансформации и настройки клавиш.
* **Сетка и прилипание (Grid & Snapping):** Привязка объектов к 3D-сетке и автоматический снаппинг к размещенным предметам.
* **Полная трансформация:** Вращение по трем осям (Pitch, Yaw, Roll), точное смещение по высоте и изменение масштаба.
* **Управление физикой и цветом:** Включение/выключение физики объектов и быстрая покраска в различные цвета.
* **Кастомизация управления:** Полная поддержка переназначения горячих клавиш с сохранением в файл.

## 🚀 Установка

1. Перейдите в раздел [**Releases**](../../releases) и скачайте актуальную версию архива.
2. Распакуйте DLL-файл мода в папку игры или используйте ваш предпочтительный DLL-инжектор (например, UE4SS или Proxy DLL).
3. Запустите **Brick Rigs**.

| :--- | :---: | :--- |
| **Открыть / Закрыть Меню** | `Y` | Показать или скрыть GUI-интерфейс мода |
| **Удержание Курсора** | `` ` `` (Тильда) | Активация курсора мыши для взаимодействия с меню |
| **Режим Редактора** | `F5` | Переключение свободной камеры |
| **Разместить объект** | `Home` | Поставить выбранный объект на сцену |
| **Удалить объект** | `Delete` | Удалить последний созданный объект |

| **Смена оси вращения** | `0` | Переключение оси (Pitch / Yaw / Roll) |

| **Масштаб** | `'` / `;` | Увеличить / уменьшить размер |

| **Цвет** | `F9` | Циклическая смена цвета |

| **Сброс** | `End` | Сброс контроля и камеры |

## 🎥 Режим редактора

Режим свободной камеры (`F5`) позволяет отвязать камеру от персонажа и свободно перемещаться по карте. При удерживании клавиши `` ` `` (Тильда) появляется курсор мыши, что дает возможность кликать по элементам GUI без потери контроля над позиции камеры.

---

## 📦 Размещение объектов

Объекты спавнятся перед камерой на настраиваемой дистанции:
* **Поворот:** поворачивайте объект вокруг выбранной оси (`0`).
* **Размер:** динамически меняйте масштаб объекта перед установкой (`'` / `;`).
* **Покраска:** выбирайте цвет для элементов модели нажатием `F9`.

---

## 📐 Сетка и снап

* **Grid Mode (`8`):** Привязывает координаты объекта к виртуальной 3D-сетке. Шаг сетки регулируется клавишами `6` и `7`.
* **Snap to Objects (`9`):** Автоматически притягивает объект к граням и коллизиям соседних предметов, упрощая постройку сложных конструкций.

---

## 💾 Сохранение и загрузка

Все пользовательские параметры (чувствительность камеры, параметры сетки, дистанции) автоматически сохраняются в файл `BRMod_settings.ini` при выходе или изменении настроек в меню.
