## 🌟 Возможности

* **Свободная камера (Free Camera):** Полный контроль над камерой для точного и удобного строительства в пространстве.
* **Интерактивное GUI-меню:** Удобный интерфейс для выбора объектов, цвета, параметров трансформации и настройки клавиш.
* **Сетка и прилипание (Grid & Snapping):** Привязка объектов к 3D-сетке и автоматический снаппинг к граням/коллизиям уже размещенных объектов.
* **Расширенная трансформация:** Вращение по трем осям (Pitch, Yaw, Roll), регулировка высоты и точное масштабирование объектов.
* **Управление физикой и цветом:** Включение/выключение физики предметов и быстрая покраска в различные цвета.
* **Кастомизация управления:** Полное переназначение всех 32 действий мода с автоматическим сохранением в конфигурационный файл.

## 🚀 Установка

1. Перейдите в раздел [**Releases**](../../releases) и скачайте актуальную версию архива.
2. Распакуйте DLL-файл мода в папку игры или используйте ваш предпочтительный DLL-инжектор.
3. Запустите **Brick Rigs**.

| Действие | Клавиша по умолчанию | Описание |
| :--- | :---: | :--- |
| **Открыть / Закрыть Меню** | `Y` | Показать или скрыть GUI-интерфейс мода |
| **Удержание Курсора** | `` ` `` (Тильда) | Активация курсора мыши для взаимодействия с меню |
| **Режим Редактора** | `F5` | Переключение режима свободной камеры |

| **Переключение моделей** | `F6` / `F7` | Выбор предыдущей / следующей модели |
| **Вращение** | `,` / `.` | Поворот объекта |
| **Смена оси вращения** | `0` | Переключение оси (Pitch / Yaw / Roll) |
| **Высота** | `PgUp` / `PgDn` | Поднять / опустить объект |
| **Масштаб** | `'` / `;` | Увеличить / уменьшить размер |
| **Физика** | `F8` | Переключить режим физики объекта |
| **Цвет** | `F9` | Циклическая смена цвета |

| **Размер сетки** | `6` / `7` | Уменьшить / увеличить шаг сетки |
| **Консоль UE** | `F3` | Вызов встроенной консоли Unreal Engine |
| **Сброс** | `End` | Сброс контроля и положения камеры |

## 🎥 Режим редактора

Режим свободной камеры (`F5`) позволяет отвязать камеру от персонажа и свободно перемещаться по карте. При удерживании клавиши `` ` `` (Тильда) появляется курсор мыши, что дает возможность кликать по элементам GUI без потери контроля над позицией камеры.

---

## 📦 Размещение объектов

Объекты спавнятся перед камерой на настраиваемой дистанции:
* **Поворот:** поворачивайте объект вокруг выбранной оси (`0`).
* **Размер:** динамически меняйте масштаб объекта перед установкой (`'` / `;`).
* **Покраска:** выбирайте цвет для элементов модели нажатием `F9`.

---

## 📐 Сетка и снап

* **Grid Mode (`8`):** Привязывает координаты объекта к виртуальной 3D-сетке. Шаг сетки регулируется клавишами `6` и `7`.
* **Snap to Objects (`9`):** Автоматически притягивает объект к граням и коллизиям соседних предметов, упрощая постройку сложных конструкций.

---

## 💾 Сохранение и загрузка

Все пользовательские параметры (чувствительность камеры, параметры сетки, дистанции спавна) и конфигурации клавиш автоматически сохраняются в конфигурационные файлы (`BRMod_settings.ini` и `BRMod_keys.ini`) при выходе или изменении настроек.
